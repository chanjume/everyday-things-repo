# Everyday Things, Two Lines

A traffic jam explained to a 10-year-old through a zipper analogy, with
an honest second line about what the analogy maps and what it leaves out.

> A traffic jam is a zipper stuck halfway: a thousand cars trying to squeeze through one tooth at a time, and the harder everyone pulls, the tighter it jams.
> The zipper maps the merge — one lane feeding the next tooth by tooth — but leaves out that drivers, unlike teeth, can choose to leave a gap and let it run smooth.

Run with `node main.ts` (Node 22). The entry is 318 characters, inside
the 1–400 character gate.
